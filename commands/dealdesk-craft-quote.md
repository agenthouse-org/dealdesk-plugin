# Craft an excellent classic quote

Follow the `dealdesk-craft-quote` skill (classic-first).

1. Confirm company, contact, and what the quote is about.
2. Ask clone vs copy-a-liked-quote vs create fresh.
3. Consult the published portfolio; confirm groups / selection / optional / `quantityEditable`.
4. Create or clone, then refine with `replace_quote_items`.
5. Use portfolio CPQ create/update only when asked for evaluated pricing (`quoteLayout` when useful).
6. Offer share link or PDF. Never delete through MCP.
